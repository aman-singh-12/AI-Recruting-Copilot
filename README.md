# AI Recruiting Copilot

An AI-powered recruiting assistant that analyzes resumes against job descriptions using Python, Streamlit, and Llama 3.

## Features

- Resume PDF Parsing
- Job Description Analysis
- Skill Matching
- Match Score Calculation
- Missing Skills Detection
- AI Candidate Evaluation
- Interview Question Generation

## Tech Stack

- Python
- Streamlit
- Ollama
- Llama 3
- PyPDF
